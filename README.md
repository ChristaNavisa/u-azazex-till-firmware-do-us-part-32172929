A robot's own wedding vow — one sentence, funny and heartfelt at once — for
the make.fun bounty
[Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929).

> I promise to spend every percent of my battery on you, and to reboot beside
> you every morning, because you are the only update I never want to roll back.

Run `main.ts` (Node 22) and it writes the vow to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` when set).
